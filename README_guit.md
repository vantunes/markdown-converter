# Markdown Converter

Aplicação desktop desenvolvida em Python para converter documentos para Markdown utilizando MarkItDown.

## Funcionalidades

- Conversão PDF → Markdown
- Conversão DOCX → Markdown
- Conversão em lote de pastas
- Preview do Markdown
- Atualização de dependências
- Interface gráfica CustomTkinter

## Instalação

```bash
python -m venv venv
venv\Scripts\activate

pip install -r requirements.txt
